# Jolian Habib — Premium Engineering Portfolio

This version builds on the **original animated Framer Motion portfolio**, not the simplified redesign.

## Run
```bash
npm install
npm run dev
```
Open the localhost URL shown in the terminal.

## Release check
```bash
npm run build
```

CV: `public/cv.pdf` is the final-year version. Update this file when changing your resume.

Project links and descriptions are editable in `src/pages/Home.jsx`.

Legacy project detail pages remain intact. The new projects open the live websites; older projects keep their detail views.
